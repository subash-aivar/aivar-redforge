# M18 Intelligence Expansion — Provider Decision Matrix

Researched against each provider's own current official documentation (not assumed from historical reputation). "IMPLEMENT NOW" means a working adapter ships this pass, disabled until an operator supplies credentials/config. "OPTIONAL ADAPTER" means the adapter code exists but ships **disabled by default** with an explicit compliance disclaimer, because the official terms carry real ambiguity or a quota too low for automated pipeline use. "REJECT" means no adapter was built.

## Summary of decisions actually shipped this pass

- **IMPLEMENT NOW (enabled once an operator configures credentials/DB path):** AbuseIPDB, AlienVault OTX, Spamhaus DROP/EDROP (keyless), RDAP, MaxMind GeoLite2 local-DB reader, IPinfo Lite (geo fallback).
- **OPTIONAL ADAPTER (built, shipped disabled, explicit compliance disclaimer in the admin UI):** GreyNoise Community (quota), abuse.ch URLhaus/ThreatFox/Feodo Tracker (commercial-use ambiguity in their own docs).
- **REJECTED:** ip-api.com (free tier explicitly non-commercial only).
